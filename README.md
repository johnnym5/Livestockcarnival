# Livestock Carnival (`livestockcarnival.ng`)

Official web portal and digital platform for **Livestock Carnival**, celebrating agriculture, livestock innovation, trade exhibitions, and cultural heritage.

🌐 **Live Website:** [https://livestockcarnival.ng](https://livestockcarnival.ng)

---

## 🚀 Key Features

- **Interactive Event Schedule:** Explore daily event lineups, seminars, exhibitions, and entertainment sessions.
- **Venue Map & Navigation:** Interactive maps powered by Leaflet to help visitors navigate venue zones, pavilions, and exhibition stalls.
- **Accreditation Portal:** Seamless registration and accreditation flows for attendees, vendors, and media personnel.
- **Attractions & Showcase:** Detailed highlights of livestock breeds, agricultural tech, competitions, and carnival highlights.
- **Media & Press Hub:** Photo galleries, press releases, and updates.
- **Contact & Support:** Inquiry forms and direct communication channels.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router, React 19)
- **Styling:** Tailwind CSS & Framer Motion
- **Maps:** Leaflet / React-Leaflet
- **Backend & Hosting:** Firebase & Hostinger (`livestockcarnival.ng`)

---

## Getting Started

First, run the development server:

```bash
cd nextjs-app
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
