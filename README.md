# Renewed Hope National Livestock Carnival 2026 (`livestockcarnival.ng`)

Official web portal and digital platform for the **Renewed Hope National Livestock Carnival 2026** (Golden Camel & Cow Carnival), celebrating Nigerian agricultural wealth, livestock innovation, B2B trade exhibitions, and cultural heritage.

🌐 **Live Portal:** [https://livestockcarnival.ng](https://livestockcarnival.ng)

---

- **09:00 - 12:00 PM** — **Commercial B2B Matchmaking & Pet/Home Arts Shows**: B2B Supplier Meet, High-Stakes Seedstock Auction, Children's Agro-Education Workshop, Open Crafted, Visual & Home Arts & Gardening Judging, Dog Show & Showmanship, Cat Show Check-in & Showmanship Contest, and Traditional Quilt Judging (Open to Public).

## 🚀 Key Platform Features

- **Interactive 3-Day Master Schedule:** Filter sessions by track (*Ceremonies & Protocols*, *Livestock & Breed Judging*, *Agribusiness & B2B*, *Entertainment & Concerts*) with integrated `.ics` calendar generation.
- **Supabase Data & Accreditation Engine:** Decoupled backend powered by Supabase PostgREST database tables, storage bucket management for PDF press credentials, and Row Level Security (RLS).
- **GIS Venue Navigation:** Interactive map viewer powered by Leaflet to explore venue zones, pavilions, and exhibition stalls at the Old Parade Ground, Abuja.
- **National Livestock Spectrum Showcase:** Visual galleries covering Bulls, Cattle, Golden Camels, Small Ruminants, Poultry, and Aquaculture.
- **Hostinger Production Deployment:** Optimized PostCSS & Tailwind CSS v3 architecture ensuring zero-error static compilation for production.

## 🛠️ Tech Stack

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router, React 19, TypeScript)
- **Styling & Motion:** Tailwind CSS v3, PostCSS, Framer Motion, Lenis Smooth Scroll
- **Database & Storage:** [Supabase](https://supabase.com/) (`@supabase/supabase-js`, PostgreSQL RLS, Storage Buckets)
- **Maps:** Leaflet & React-Leaflet
- **Deployment:** Hostinger Production Web Hosting ([`livestockcarnival.ng`](https://livestockcarnival.ng))
